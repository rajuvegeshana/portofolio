# README

## Portfolio Redesign for Harikrishna

A static, high-performance product design portfolio with a built-in local admin panel.

### Tech Stack
- React 18, Vite, Tailwind CSS
- Node.js/Express (Local Admin)
- GitHub Pages Deployment

### Core Features
- Three distinct visual themes (Editorial, Swiss, Creative).
- Local content management (Edit without code).
- Verified Accenture/Visa and project history.

### Quick Start
- `npm install`
- `npm run dev` (Site)
- `npm run admin` (Admin Panel)

The content server runs locally by default. GitHub Pages serves the public build from the `gh-pages` branch; protected case studies and remote admin editing require a hosted server. See `docs/deployment.md` for release steps. Earlier public commits may still contain protected text; a new build does not remove that history.
